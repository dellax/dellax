### Products I build and run

- **[SOFO](https://sofo.sk)** – reads Slovak public procurement sources every day and sends each company the tenders it can bid on.<br><sub>TypeScript · TanStack Start · PostgreSQL · LLM</sub>
- **[Pychle](https://pychle.sk)** – public procurement documents filled in a form, generated as Word, Excel and PDF.<br><sub>TypeScript · TanStack Start · tRPC · PostgreSQL</sub>
